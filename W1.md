# 🧭 Kubernetes Q&A Master Plan — Week 1  
### 🗓️ Core Concepts: Pods, Deployments, Services

---

## 1. What is Kubernetes?
Kubernetes (K8s) is an **open-source container orchestration platform** that automates the **deployment, scaling, and management** of containerized applications.

---

## 2. What is a Pod?
A **Pod** is the **smallest deployable unit** in Kubernetes.  
It can contain **one or more containers** that share the same **network namespace, storage, and configuration**.

---

## 3. Difference Between a Pod and a Container
| Concept | Description |
|----------|--------------|
| **Pod** | A wrapper around one or more containers; managed by Kubernetes. |
| **Container** | The actual running environment (like Docker) that executes your app inside the Pod. |

Kubernetes schedules **Pods**, not individual containers.

---

## 4. What is a Deployment?
A **Deployment** is a higher-level abstraction that manages **ReplicaSets** and **Pods**.  
It handles **rolling updates**, **scaling**, and **rollbacks** automatically.

---

## 5. What is a ReplicaSet?
A **ReplicaSet** ensures that a specified number of **identical Pods** are running at all times.

---

## 6. What is a Service in Kubernetes?
A **Service** provides a **stable network endpoint** to access Pods — even when their IPs change.  
It uses **labels and selectors** to route traffic to the right Pods.

---

## 7. Types of Services

| Type | Description | Use Case |
|------|--------------|----------|
| **ClusterIP** | Default type. Exposes the Service **internally** within the cluster. | Internal-only communication. |
| **NodePort** | Exposes the Service on **each Node’s IP and a static port**. | Access apps externally via `<NodeIP>:<NodePort>`. |
| **LoadBalancer** | Creates an **external load balancer** (on supported cloud providers). | Internet-facing apps. |
| **ExternalName** | Maps the Service to an **external DNS name**. | Connect to external services. |

---

## 8. What is `kubectl`?
`kubectl` is the **command-line tool** used to interact with the **Kubernetes API Server**.  
You use it to deploy, inspect, and manage cluster resources.

---

## 9. Difference Between `kubectl apply` and `kubectl create`

| Command | Type | Behavior |
|----------|------|-----------|
| **apply** | Declarative | Creates or updates resources from a manifest file. |
| **create** | Imperative | Fails if the resource already exists. |

---

## 10. What is a Namespace?
A **Namespace** is a logical partition inside a cluster that isolates resources.  
Think of it like **folders** in a filesystem — useful for organizing environments (e.g., dev, staging, prod).
